设计概览

鼠尾草绿 + 衬线标题 + 结构即纹理 —— 画廊自身设计系统，6类20变量DTCG对齐。杂志编辑 风格 · 亮色 配色 · 正式度 适中。

适用场景

设计系统展示、品牌页、个人作品集、知识平台

不适合

电商促销页、数据仪表盘、游戏界面

设计基因

杂志编辑 / gallery-index / 衬线标题(Noto Serif SC) + 无衬线正文(Helvetica Neue)，大字重标题，高行距正文，letter-spacing收紧

为什么标题用 Noto Serif SC / Source Han Serif SC / Songti SC + 正文用 Helvetica Neue / PingFang SC / Microsoft YaHei UI？
展示字体 --display 选用 Noto Serif SC / Source Han Serif SC / Songti SC，正文 --body 选用 Helvetica Neue / PingFang SC / Microsoft YaHei UI。。衬线标题+无衬线正文的强对比策略：标题负责"宣言式视觉冲击"（极大字号+极窄字距），正文负责"可读的信息传递"。
