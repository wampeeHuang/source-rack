分类标准说明

档位（Tier）

S 权威领域一手标准信息，绝不出错。每领域 ≤5。人工审查，每月。
A 高质量专业可靠，偶尔遗漏。每领域 ≤20。3次质量问题 → 降B。
B 可用覆盖面宽，需交叉验证。连续5次高质量 → 升A。每两周审。
C 试探新收录，待观察稳定性。不主动搜索。通过 → 升B。每周审。
D 降级曾经收录，已不再使用。不参与搜索。可恢复至C。
✕ 黑名单内容农场/AI垃圾/付费墙过重。永不使用。随时加。

信息源类型（Source Type）

权威源一手标准信息，领域最可靠。策略：site: 直接定位。
聚合源收集/精选他人内容。策略：站内搜 → 提取原始链接。
平台跨域 UGC，需限定频道/作者。策略：channel-search 或 @账号。
社区用户讨论/问答，质量波动。策略：搜 + 标注置信度。
AI原生结构化好、API友好、抓取快。策略：直接调 API 或结构化抓取。

搜索优先级

第 1 轮S+A 档源。命中率高、token 少、结果可信。命中即止。
第 2 轮B 档补充。第 1 轮无满意结果时触发。需交叉验证。
兜底通用搜索。B 也不够时全量搜。过滤黑名单域名。
不主动查C 档仅手动触发。D 档不参与搜索。
过滤黑名单全程排除，不进入任何搜索结果。
